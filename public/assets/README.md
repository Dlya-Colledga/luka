# Медиафайлы LUKA

Скопируйте из оригинального репозитория `assets/` в эту папку, сохранив структуру:

- `media/bg.webm` — фоновое видео главной страницы;
- `audio/heart.mp3` — два удара сердца при входе;
- `audio/bg.ogg` — фоновая музыка (при необходимости используется `audio/bg.mp3`).

При сборке Vite файлы из `public/` копируются в корень `dist/` без изменения путей.
Медиа не включены в ZIP, поскольку отсутствуют в предоставленной локальной версии HTML.
