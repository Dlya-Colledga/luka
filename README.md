# LUKA — React + Vite + TypeScript

Перенос оригинальной главной страницы LUKA из единого `index.html` на React, Vite и TypeScript.

## Запуск

Нужен **Node.js 22.12+** (либо совместимая актуальная версия 20.19+).

```bash
npm install
npm run dev
```

Vite выведет локальный адрес страницы (по умолчанию `http://localhost:5173`).

Проверка типов и сборка:

```bash
npm run typecheck
npm run build
npm run preview
```

## Важно: медиа

В ZIP входят все исходники React, но **не сами медиафайлы**. Перенесите файлы из
[исходного репозитория LUKA](https://github.com/dlya-colledga/luka) в `public/assets/`:

```text
public/
  assets/
    media/
      bg.webm
    audio/
      heart.mp3
      bg.ogg        # либо bg.mp3 — запасной формат
```

Без медиа страница не зависнет навсегда: прелоадер завершится, но видео и музыка
не будут воспроизводиться. Проверяйте звуковые эффекты с файлами оригинального проекта.

## Что сохранено

- Лавандовая тема без переключения оформления.
- Типографичный прелоадер LUKA с процентом загрузки и двумя пульсациями логотипа.
- Два удара сердца и фоновая музыка через Web Audio после нажатия.
- Кинематографичное открытие главной с диафрагмой, мягкой засветкой и появлением текста.
- `bg.webm`, затемнение **40%**, размытие **15px** после перехода.
- Параллакс видео против курсора, плавный возврат при уходе указателя.
- Виньетка только на главной, а не в прелоадере; без свечения логотипа.
- Уважение `prefers-reduced-motion` и тайм-ауты при неудачной загрузке файлов.

## Структура

```text
src/
  App.tsx                    # Компоновка и фазовое состояние
  components/
    Preloader.tsx            # Прелоадер и кнопка начала
    Landing.tsx              # Основной экран и фоновое видео
  hooks/
    useMediaPreloader.ts     # Загрузка аудио, видео и шрифтов
    useHeartbeatSequence.ts  # Web Audio и тайминг перехода
    useVideoParallax.ts      # Параллакс с rAF
  lib/
    assets.ts                # Пути к ассетам с учётом base Vite
    heartbeat.ts             # Временные интервалы сердцебиения
  styles.css                # Стили и анимации
```

## Публикация на GitHub Pages

В `.github/workflows/deploy.yml` есть workflow сборки Vite и публикации `dist/`.
В репозитории GitHub откройте **Settings → Pages → Build and deployment → Source** и
выберите **GitHub Actions**. Загрузите эти файлы и медиа в репозиторий; после пуша в
`main` workflow опубликует сайт.

`base: './'` в `vite.config.ts` позволяет использовать относительные пути на GitHub Pages.
Сам по себе GitHub Pages не компилирует `.tsx` — необходимо публиковать `dist/`.
